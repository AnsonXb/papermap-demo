# PaperMap — 论文知识图谱生成器

输入一个研究关键词，自动检索真实论文、生成引用关系图谱，并给出阅读路径、文献综述大纲与领域知识体系。

**在线使用**：<https://ansonxb.github.io/papermap-demo/>

---

## 解决什么问题

- 面对上百篇论文，不知道从哪篇开始读、哪些是核心文献
- Connected Papers 只能看引用网络，看完图仍然不知道该先读什么
- 读完十几篇论文，不知道怎么把它们组织成综述框架

PaperMap 的答案是：**图谱 + 排序 + 大纲**，三步把陌生领域拆成可执行的阅读计划。

## 核心能力

| 能力 | 说明 |
|------|------|
| 关键词检索 | 中文关键词自动映射为学术英文术语（30+ 领域词表），检索 2.5 亿+ 文献 |
| 真实引用关系 | 基于 OpenAlex 被引网络构建实线引用边，另以虚线标注主题相关 |
| 重要度排序 | 综合评分 = 年均引用 50% + 总引用 20% + 年份新鲜度 20% + 基础分 10% |
| 交互图谱 | 拖拽平移、滚轮/双指缩放、悬停高亮一阶关联、点击查看摘要与原文 |
| 列表视图 | 小屏或快速浏览时切换为按重要度排序的论文列表 |
| 阅读路径 | 奠基论文优先 + 综合权重降序，点条目即可在图中定位，可导出 Markdown |
| 综述大纲 | 按奠基 / 发展 / 前沿三段自动组织，可导出 Markdown 用于开题报告 |
| 领域知识体系 | 按论文类型聚合为可折叠概念树，点击论文查看详情 |

## 数据来源与实现

- **主数据源**：OpenAlex（2.5 亿+ 学术文献，含被引数与被引网络，CC0 开放数据，浏览器可直连）
- **备用数据源**：Crossref（OpenAlex 不可用时自动降级，图谱仍可用，仅缺少引用边）
- **实现方式**：单文件纯前端（原生 JavaScript + 原生 SVG），无框架、无构建、无后端、无 API Key
- **容错**：请求带超时与自动重试，任一步骤失败都不会阻塞主图；完全离线时退回内置示例数据并明确标注
- **部署**：把 `index.html` 放到任意静态托管即可（GitHub Pages / Vercel / 对象存储）

> `papermap.html` 仅为兼容旧链接保留的跳转页，实际入口是 `index.html`。

## 文件说明

```
index.html      应用本体（HTML + CSS + JS 全部内联，可直接双击打开）
papermap.html   旧链接跳转到 index.html
README.md       本文档
```

## 与同类工具对比

| 维度 | Connected Papers | ResearchRabbit | PaperMap |
|------|:---:|:---:|:---:|
| 引用网络可视化 | 支持 | 支持 | 支持（原生 SVG，可缩放拖拽） |
| 中文关键词搜索 | 不支持 | 有限支持 | 内置术语映射 |
| 无需注册 | 需注册 | 需注册 | 打开浏览器即用 |
| 阅读路径推荐 | 按时间/引用数 | 按相似度 | 综合权重 + 奠基标记 + 可导出 |
| 综述大纲生成 | 不支持 | 不支持 | 三段式自动组织 + 导出 Markdown |
| 离线可用 | 不支持 | 不支持 | 内置示例数据 |

## 已知限制

- 每年新增论文的引用数据由 OpenAlex 更新，最新论文的引用数可能偏低
- 主题相关边由标题/摘要关键词相似度计算，仅作补充参考，不代表真实引用
- 综述大纲由规则模板生成，需结合原文核对后使用
